# 望江客栈 Web 预览

这是由当前小游戏运行构建发布的公开试玩包，GitHub Pages 从仓库根目录提供服务。

- 在线入口：<https://xi-guanguan.github.io/wangjiang-inn-web/>
- 当前构建：`inn-r6-taptap-ad-20260924`
- 运行方式：Canvas-only；与小游戏使用同一套领域逻辑和运行素材。
- 本仓库只含可运行网页产物：`index.html`、构建清单和 `minigame-assets/`。

页面不会公开本地调试、验收或摆位工具。即使地址带有 `?debug=1`，公开预览也会自动回到普通玩家模式；需要调试请使用本地源码工作区。

微信小游戏导入包、研究材料、Maker 配置、开发凭据与个人存档均不在本仓库中。
